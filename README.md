# vaishh. — personal journal

A minimalist, editorial personal journal and reflection space inspired by clean typography, digital stationery, and deliberate thoughts.

## Overview

- **Aesthetic**: Warm paper & obsidian dark themes, editorial serif typography (`Newsreader`), monospace metadata accents (`JetBrains Mono`), and humanist sans body (`Plus Jakarta Sans`).
- **Dynamic Header**: `vaishh.` brand with theme toggle (`☼` / `☾`) and dynamic current date.
- **Greeting**: Personalized and editable greeting (`hey, vaishnav. what's on your mind today?`).
- **Tactile Quick Writer**: `+ write something` box with keyboard shortcut (`N`).
- **Recent Thoughts**: Chronological reflections with date, title, quote preview, and subtle dividers.
  - Included seed entries:
    - **Mission 2027** (`30 oct 2026`) — *my life, my thoughts, my journey.*
    - **things i wanted to say** (`29 oct 2026`) — *some thoughts are better written.*
    - **the quiet hours** (`24 oct 2026`) — *where clarity lives.*
- **Distraction-Free Writer**: Full-screen modal writer with draft auto-saving, word counts, tags, markdown formatting support, and `Ctrl+Enter` to save.
- **Reader View**: Immersive reading mode with reading time estimates, formatted paragraphs, bullet lists, blockquotes, copy-to-clipboard, edit, and delete.
- **Archive**: Filter by keywords and tags, view total entry/word counts, with JSON backup export and import.
- **About**: Vaishnav's manifesto, vision for Mission 2027, and guiding principles.

## Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `N` or `W` | Open new thought composer |
| `T` | Toggle Light / Dark mode |
| `Esc` | Close reader or writer |
| `Ctrl + Enter` / `Cmd + Enter` | Save thought in editor |
